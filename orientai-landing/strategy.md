# OrientAI + AI Server 官網首頁策略與文案架構

## 新版主軸

新版首頁不再只是「類 MaiAgent 的企業 AI 平台」敘事，而是改成：

> OrientAI 是企業安全啟用 AI Agent 的工作平台；AI Server 是企業可控的模型、資料與推論底座。

產品頁要讓買方快速理解三件事：

1. OrientAI 主打企業 Agent 工作平台，不只是聊天框。
2. AI Server 補上資料主權、地端/私有部署與推論成本控管。
3. digiRunner 的 API 治理與權限控管經驗，是 OrientAI 安全使用 Agent 的核心差異。

## 參考來源萃取

### AISO Portal

AISO 的吸引力在於把 AI 採購講成「硬體 + 軟體 + 部署支援」的一體化路徑，核心訊息是 Sovereign AI、資料主權、成本降低、Ready-to-use，以及 Find / Match / Deploy。

OrientAI 可借用的敘事：

- AI Server 是企業主權 AI 的基礎設施。
- OrientAI 是跑在 AI Server 上、面向使用者的 Agent 工作平台。
- 從需求、軟體、硬體到部署支援，TPIsoftware 能提供完整導入路徑。

### 產品主管 PPT

PPT 的核心不是單純「digiRunner AI Marketplace」，而是：

- AI Gateway 從 1.0 模型通道，升級成 2.0 Agent 控制塔。
- Marketplace 把複雜 API / MCP / Agent 技術變成使用者可理解的服務貨架。
- 企業需要標準化「發現、試用、申請、主管核准、落地執行」的安全閉環。
- AI 價值鏈分成 LLM、MCP Tools、Skills、AI Agent 四層，且都需要治理。
- 相較傳統 AI 部署，Marketplace 模式能改善權限、成本、審計與資源共享。

### 產品影片

影片應該作為首頁 Hero 的主視覺或第一屏 Demo，而不是放在很後面。使用者需要一眼看到：

- 知識庫助手
- 可視化工具/Agent 建置
- Vibe coding / tool builder 體驗
- No-code / Low-code 的產品感

## 首頁架構

### 1. Hero

標題：

> 讓企業安全啟用 AI Agent 的工作平台

副文：

> OrientAI 以 digiRunner 的企業權限控管與 API 治理經驗為核心，搭配 AI Server 的私有部署底座，讓企業能從 Agent 市集快速啟用智慧體，打造知識庫助手、報告流程與 Vibe coding 工具。

右側：

- 嵌入 `digiAI Studio v1.1.mp4`
- Demo 標籤：Knowledge Agent、Tool Builder、No-code

### 2. 產品主軸條

> OrientAI 主打企業 Agent 工作平台，搭配 AI Server 形成「安全治理、快速啟用、私有部署」的一體化 AI 落地方案。

標籤：

- 企業權限控管
- Agent 市集
- 知識庫助手
- Vibe coding
- AI Server
- API / MCP 串接
- SI 導入服務

### 3. AI Server

主標：

> 把 AI Agent 跑在企業可掌控的基礎設施上。

四個賣點：

- 資料主權
- 成本可控
- 即插即用
- 彈性模型

### 4. 企業 AI Agent 為什麼需要治理

主標：

> 企業真正需要的不是更多 AI 工具，而是能安全控管 AI Agent 的作業系統。

三個痛點：

- Shadow AI 與資源浪費
- 資料外洩與權限失控
- 業務單位難以自助啟用

### 5. OrientAI 三個主打特色

- 企業權限控管與安全
- Agent 市集
- 知識庫助手與 Vibe coding

### 6. Agent Marketplace

主標：

> 把複雜的 AI 技術變成企業內部可領用的服務貨架。

標準流程：

1. Find：找到 Agent、Skill 或 MCP 工具。
2. Match：比對資料、權限、模型與 AI Server 資源。
3. Approve：主管或系統依政策核准。
4. Deploy：Agent 在受控環境執行並留下紀錄。

### 7. 四層 AI 價值鏈

- Level 1：LLM 模型
- Level 2：MCP 工具
- Level 3：Skills
- Level 4：AI Agent

這段可把 PPT 的架構濃縮成網站可讀的版本。

### 8. 比較表

比較 OrientAI、傳統 AI 部署、個人 AI 工具、單點知識庫：

- 權限管控
- 資源與成本
- 安全審計
- 工具共享
- 部署底座

### 9. 專業服務

TPIsoftware 必須保留 SI 與顧問服務，因為這是和純軟體平台最大的不同。

- 企業 AI 藍圖顧問
- 專案開發與 SI
- 講師培訓與工作坊
- 上線營運優化
